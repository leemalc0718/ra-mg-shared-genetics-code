# Official software resources

The commands in this repository were normalized against the following primary documentation. Access dates and exact software revisions should be recorded with each final analysis.

- [LDSC repository](https://github.com/bulik/ldsc) and [summary-statistics format](https://github.com/bulik/ldsc/wiki/Summary-Statistics-File-Format)
- [LDSC cell-type-specific analysis tutorial](https://github.com/bulik/ldsc/wiki/Cell-type-specific-analyses)
- [GNOVA repository](https://github.com/xtonyjiang/GNOVA)
- [ρ-HESS local genetic covariance tutorial](https://huwenboshi.github.io/hess/local_rhog/) and [input format](https://huwenboshi.github.io/hess/input_format/)
- [GWAS-PW repository and input specification](https://github.com/joepickrell/gwas-pw)
- [MiXeR user documentation](https://github.com/precimed/mixer)
- [TwoSampleMR documentation](https://mrcieu.github.io/TwoSampleMR/) and [allele harmonization guide](https://mrcieu.github.io/TwoSampleMR/articles/harmonise.html)
- [CAUSE repository](https://github.com/jean997/cause)
- [MAGMA.Celltyping documentation](https://neurogenomics.github.io/MAGMA_Celltyping/) and [pipeline reference](https://neurogenomics.github.io/MAGMA_Celltyping/reference/celltype_associations_pipeline.html)
- [MTAG repository](https://github.com/JonJala/mtag)
- CPASSOC software page referenced by the method publication: `http://hal.case.edu/~xxz10/zhuweb/`
- [coloc documentation](https://chr1swallace.github.io/coloc/) and [FAQ on dense regional variant sets](https://github.com/chr1swallace/coloc/blob/main/FAQ.md)
- [FUSION repository](https://github.com/gusevlab/fusion_twas) and [association script interface](https://github.com/gusevlab/fusion_twas/blob/master/FUSION.assoc_test.R)
- [SMR software documentation](https://cnsgenomics.com/software/smr/)
- [Seurat PBMC guided tutorial](https://satijalab.org/seurat/articles/pbmc3k_tutorial) and [Seurat v5 layer commands](https://satijalab.org/seurat/articles/seurat5_essential_commands.html)

Third-party tutorials, copied installation logs, and historical local paths are not treated as authoritative interfaces.
